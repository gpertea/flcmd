# Keybindings (Total Commander defaults)

All bindings live in the keymap action table and are user-remappable via
config. Stage column shows when each lands.

| Key | Action | Stage |
|-----|--------|-------|
| Tab | Switch active pane | 1 |
| Enter | Open dir / run or open file | 1 |
| Backspace, Ctrl+PgUp | Parent directory | 1 |
| Alt+Left / Alt+Right | History back / forward (also toolbar arrows) | 1 |
| Ins | Toggle select, move down | 1 |
| Space | Toggle select (+ dir size) | 1 |
| Num+ / Num- / Num* | Select/unselect by glob, invert | 1 |
| Ctrl+A | Select all | 1 |
| Ctrl+F3..F6 | Sort by name/ext/size/date | 1 |
| Ctrl+R | Refresh pane | 1 |
| Ctrl+U | Swap panes | 1 |
| Ctrl+Left/Right | Open dir under cursor in other pane | 1 |
| Alt+F4 | Quit | 1 |
| Letter keys / Ctrl+S | Quick search in pane | 1 |
| F5 | Copy selection to other pane | 2 |
| F6 | Move/rename to other pane | 2 |
| Shift+F5 / Shift+F6 | Copy/rename in same dir | 2 |
| F2 | Rename in place | 2 |
| F7 | New directory | 2 |
| F8, Del | Delete | 2 |
| Alt+Enter | Properties | 2 |
| Ctrl+L | Calculate occupied space | 2 |
| F3 | View file (built-in viewer) | 3 |
| F4 | Edit file (external editor) | 3 |
| Shift+F4 | Create + edit new file | 3 |
| Ctrl+PgDn | Open archive as directory | done |
| Alt+F9 | Unpack archive | 5 |
| Alt+F5 | Pack selection | 5 |
| Ctrl+N | SSH/SFTP connect | done |
| Ctrl+T / Ctrl+W | New / close tab | 7 |
| Ctrl+Tab | Next tab | 7 |
| Ctrl+D | Directory hotlist | 7 |
| Ctrl+Q | Quick view panel (image preview) | done |
| Ctrl+Shift+F1 | Thumbnail view toggle | done |
| Dbl-click panel header | Folder shortcuts (bookmarks) menu | done |
| Alt+F1 / Alt+F2 | Left/right drive-root menu | 7 |
| Alt+F7 | Find files | 7 |
| Ctrl+B | Branch view (flatten subdirs) | 7 |

Viewer (F3) internal keys: 1/2/3 text-bin-hex mode, W wrap, N/P next/prev
file, 4 image (z cycles fit/fit-width/100% zoom), F7 search, Esc/Q close --
matching TC's Lister where sensible.
